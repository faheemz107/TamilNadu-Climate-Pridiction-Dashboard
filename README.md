# Tamil Nadu Climate Prediction Dashboard

## Project Overview

This project predicts temperature across Tamil Nadu districts using Machine Learning and visualizes the results using Power BI.

## Objectives

- Analyze Tamil Nadu climate data
- Predict temperature using Machine Learning
- Compare actual and predicted temperature
- Analyze district-wise temperature trends
- Visualize climate insights using Power BI

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Machine Learning
- Power BI
- Git & GitHub

## Machine Learning Models

### Linear Regression
R² Score: 0.9523

### Random Forest
R² Score: 0.9985

## Dataset

The dataset contains weather information from Tamil Nadu districts.

The original dataset is not included in this repository because it exceeds GitHub's 100 MB file size limit.

## Dashboard

The Power BI dashboard contains:

- Model R²
- Average Temperature
- Total Districts
- District-wise Temperature
- Monthly Temperature Trend
- Actual vs Predicted Temperature
